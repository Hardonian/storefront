API example

# Create a chat job
curl -X POST https://your-instance.com/api/v1/jobs \
  -H "X-API-Key: your-key" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "chat",
    "model": "hermes3:latest",
    "prompt": "Explain quantum computing in 3 sentences",
    "max_tokens": 200
  }'

# Response includes job_id and credit cost
{
  "job_id": "job_abc123",
  "status": "queued",
  "credits_cost": 1,
  "estimated_time_s": 2.3
}

# Get results with signed delivery
curl https://your-instance.com/api/v1/delivery/{token}

How it works

1. Buy credits

Prepaid credit model via Stripe. No metered billing. No surprise bills. Credits are provisioned after verified payment.

2. Create jobs

Authenticated API with API-key isolation. Each job specifies model, prompt, and execution bounds. Credits are consumed atomically.

3. Get results

Signed delivery URLs with expiration. Webhook callbacks for async jobs. Full audit trail in the usage ledger.
